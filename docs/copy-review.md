# ROUND 문구 검토

검토 기준: `a2ef3c3`의 웹 화면, 오류 안내, 접근성 문구와 주요 개발·운영 문서.
반영 상태: 화면 문구 U01~~U22와 문서 표현 D01~~D08을 적용했다. 아래 원문과 위치는 검토 당시 기준이다.
같은 문구를 쓰는 접근성 안내와 기존 테스트도 함께 수정했다.

## 적용 시 유지할 의미

- **수신 미확인**은 메시지 미도착이나 읽지 않음과 다르다. 채팅 상태와 재전송 안내에서 이 구분을 유지한다.
- **이 참가자 다시 연결**과 **방 다시 입장**은 처리 범위가 다르므로 같은 버튼 이름으로 합치지 않는다.
- **내가 듣는 음량**, **카메라 전송 품질**, **수신 품질**은 각각 내 재생 음량, 내가 보내는 영상, 상대에게서 받는 상태를 뜻한다.
- 방장의 **비디오 끄기**는 화면 공유에도 적용될 수 있다. ‘미디어’를 일괄적으로 ‘카메라’로 바꾸지 않는다.
- 기술 문서의 WebRTC·TURN·JWT·SDP·ICE, 트랙 소유권처럼 정확한 의미가 있는 용어는 유지한다. ‘경계’와 ‘소유’도 보안 구분이나 자원 책임을 설명할 때는 사용할 수 있다.
