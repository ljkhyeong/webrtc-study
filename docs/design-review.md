# 디자인 검토

- 검토일: 2026-09-11
- 기준: `78d8c16`의 입장 준비·통화·채팅·장치 설정 화면
- 판단: 전면 개편 대신 부분 보완

영상 중심 배치와 차분한 녹색 계열은 소규모 스터디에 맞는다. BATON·공유 링크에서
입장하는 흐름도 목적에 맞아 유지했다. 화면 사이의 시각적 차이와 작은 글자, 불필요한
움직임을 줄이는 데 집중했다.

| 항목        | 보완 내용                                                                                                                        |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 통화 조작부 | 밝은 배경을 통화 화면과 같은 어두운 색으로 변경. 활성 기능은 녹색, 음소거는 중립색, 종료는 붉은색으로 구분.                      |
| 글자·버튼   | 입장 제목과 참가자 이름 표시를 고딕 계열로 통일. 안내·버튼 글자를 키우고 모바일에서는 단어 단위로 줄바꿈. 키보드 초점 표시 강화. |
| 입장 준비   | 주요 버튼을 녹색으로 통일. 초기 모바일 미리보기 높이를 줄이고 장치 확인 후에는 버튼 영역을 확보.                                 |
| 배경·움직임 | 장식용 광원·강한 그림자를 줄이고, 조작부 지연 등장과 연결 테두리의 반복 애니메이션 제거.                                         |

변경은 [스타일](../apps/web/src/styles.css)에 한정했다. 외부 글꼴·이미지·새 의존성은 추가하지 않았다.

웹 빌드와 형식 검사를 통과했다. Chromium·WebKit에서 1280px·390px·320px 화면,
2명·6명 배치, 채팅·장치 설정과 통화 버튼의 키보드 초점을 확인했다. Chromium의 가상
장치로 입장 전 마이크·카메라를 끈 상태의 미리보기 간격도 확인했다.
주요 버튼의 기본 상태 글자 대비는 4.77:1~9.48:1이다. 실제 모바일 기기와 외부망 통화
품질 검증은 이번 디자인 검토 범위에 포함하지 않는다.
